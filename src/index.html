Propósito del Proyecto

Construcción gradual de una aplicación web desde fundamentos frontend (HTML5/CSS3) hasta integración de servicios de backend y despliegue.

Arquitectura del Sistema

Nginx (Proxy / Servidor Web)

Atiende peticiones HTTP en el puerto 8000 sirviendo archivos estáticos con recarga directa por volumen.

Contenedores Docker

Aislamiento total del entorno de desarrollo sin contaminar el sistema operativo base.

Control de Versiones

Gestión de ramas y trazabilidad de cambios sincronizados con GitHub vía llaves SSH.
