Etiquetas Básicas para Empezar

Este es un párrafo tradicional creado con la etiqueta <p>.

Probando el flujo de trabajo con Git y control de versiones.

  • <h1> al <h6>: Jerarquía de títulos (usa un solo h1 por página).
  • <ul> y <li>: Listas sin orden (viñetas).
  • <ol> y <li>: Listas numeradas.
  • <a href="...">: Enlaces o hipervínculos.
